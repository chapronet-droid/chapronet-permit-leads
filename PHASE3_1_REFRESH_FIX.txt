CHAPRONET PHASE 3.1 — CONFLUENCE REFRESH FIX

This patch fixes:
  'ConfluenceClient' object has no attribute 'extract_page_id'

The dashboard now extracts the page ID directly from the saved Confluence URL,
so the Refresh Confluence Page button no longer depends on that missing method.

INSTALL
1. Close the black run_dashboard terminal window.
2. Extract this ZIP into:
   Downloads\ChaproNet_Daily_Lead_System_v2\chapronet_permit_leads
3. Replace:
   src\dashboard.py
4. Double-click run_dashboard.bat.
5. Select the same permit and click Refresh Confluence Page.

No reinstall is required. This does not change .env, tokens, Jobber records, or
existing Confluence pages.
